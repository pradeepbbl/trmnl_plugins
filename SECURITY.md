# Security Policy

## Supported versions

Only the latest release of each plugin (the most recent `<plugin>-vX.Y.Z` tag)
is supported.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub's
[private vulnerability reporting](https://github.com/pradeepbbl/trmnl_plugins/security/advisories/new)
("Security" tab → "Report a vulnerability").

Helpful details: the affected plugin and version, steps to reproduce, and the
impact you expect. Don't include real API keys or tokens.

You can expect an acknowledgement within a few days. This is a
volunteer-maintained project, so fixes are made on a best-effort basis.

## Scope

In scope: the Liquid templates, settings, and CI workflows in this repository.

Out of scope:

- The TRMNL platform and devices themselves. Report those to
  [TRMNL](https://usetrmnl.com).
